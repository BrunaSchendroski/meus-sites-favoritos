## Sobre o projeto

Página desenvolvida em HTML para apresentar cinco sites favoritos. Cada site possui um título, uma imagem ilustrativa e um link para acesso.

## Como executar

1. Baixe ou clone este repositório.
2. Mantenha a pasta `imagens` no mesmo diretório do arquivo `index.html`.
3. Abra o arquivo `index.html` em um navegador.
